# Notice2Action AI

### Smart Student Assistant

Notice2Action AI is an AI-powered student assistant that converts college notices into easy-to-understand summaries, important deadlines, instructions and actionable tasks.

## Features

- Upload college notices in PDF format.
- AI-powered notice summarization.
- Tamil and English language support.
- Important dates and deadline extraction.
- Student action checklist.
- Checklist progress tracking.
- Download analysis report.

## Technologies Used

- Python
- Flask
- HTML, CSS and JavaScript
- Google Gemini AI
- PyPDF

## Installation

1. Clone this repository:

   `git clone https://github.com/harinidavidson26-blip/Notice2Action-AI.git`

2. Open the project folder.

3. Install dependencies:

   `pip install flask pypdf google-genai`

4. Set your Gemini API key as the `GEMINI_API_KEY` environment variable.

5. Run the application:

   `py app.py`

6. Open your browser and visit:

   `http://127.0.0.1:5000/`

## Who Is It For?

Notice2Action AI is designed for college students who want to understand notices quickly and keep track of important academic deadlines.
